# Скрипт сравнения отчётов SAPE

## Описание
Скрипт `compare_reports.py` сравнивает автоматически сгенерированный отчёт с ручным заполнением и проверяет:

- ✅ Расхождения в показах и кликах (допустимо 0.01%)
- ✅ Расхождения в досмотрах (для видео кампаний)
- ✅ Корректность охватов (частота показы/охват ≤ 3.0)
- ✅ Итоговый охват не больше суммы дневных охватов

## Использование

```bash
python3 compare_reports.py <автоматический_отчёт.xlsx> <ручной_отчёт.xlsx>
```

### Пример

```bash
python3 compare_reports.py "/Users/annabereznyak/Downloads/Копия Акира Оил.xlsx" "/Users/annabereznyak/Downloads/Акира Оил.xlsx"
```

## Вывод скрипта

Скрипт выводит детальную информацию по каждому листу и каждой кампании:

- **✅** - Проверка пройдена
- **❌** - Найдена ошибка
- **⚠️** - Предупреждение

### Что проверяется:

1. **Дневные данные:**
   - Показы (допустимое расхождение: 0.01%)
   - Клики (допустимое расхождение: 0.01%)
   - Досмотры (допустимое расхождение: 0.01%)

2. **Охваты:**
   - Частота (показы/охват) для каждого дня ≤ 3.0
   - Итоговый охват ≤ сумма дневных охватов

3. **Итоговые значения:**
   - Сумма показов
   - Сумма кликов
   - Сумма досмотров

## Итоговый результат

В конце выводится общий итог:
- Количество ошибок
- Количество предупреждений

Exit code:
- `0` - все проверки пройдены
- `1` - найдены ошибки

## Требования

- Python 3.9+
- openpyxl

```bash
pip install openpyxl
```

## Примечания

- Скрипт автоматически определяет формат отчётов (с ID кампаний или без)
- Сравнивает секции по порядку если ID кампаний не найдены
- Конвертирует даты из формата datetime в строку
- Пропускает пустые секции и листы без данных
