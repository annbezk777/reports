## Шаг 2: Настроить Google Sheets API

### 2.1 Создать Service Account

1. Откройте [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект (или используйте существующий)
3. Включите **Google Sheets API**:
   - Перейдите в "APIs & Services" > "Library"
   - Найдите "Google Sheets API"
   - Нажмите "Enable"

4. Создайте Service Account:
   - Перейдите в "APIs & Services" > "Credentials"
   - Нажмите "Create Credentials" > "Service Account"
   - Введите название (например: "sape-reports")
   - Нажмите "Create and Continue"
   - Пропустите роли (необязательно)
   - Нажмите "Done"

5. Создайте JSON ключ:
   - Найдите созданный Service Account в списке
   - Нажмите на него
   - Перейдите во вкладку "Keys"
   - Нажмите "Add Key" > "Create new key"
   - Выберите JSON
   - Сохраните файл

### 2.2 Сохранить credentials

```bash
# Переместите скачанный JSON файл в папку проекта
mv ~/Downloads/your-project-xxxxx.json "/Users/annabereznyak/Desktop/Все проекты/sape_reports_panel/google_credentials.json"
```

### 2.3 Дать доступ к Google Sheets

1. Откройте JSON файл и найдите поле `client_email` (например: `sape-reports@your-project.iam.gserviceaccount.com`)

2. Откройте вашу Google Sheets таблицу

3. Нажмите "Настройки доступа" (Share)

4. Вставьте email из `client_email`

5. Дайте права "Редактор"

6. Нажмите "Готово"

## Шаг 4: Добавить первый отчет

### 4.1 Добавить аккаунт SAPE

1. Откройте http://localhost:5005/accounts
2. Нажмите "+ Добавить аккаунт"
3. Введите:
   - Email: `full_media_ppl@sape.ru`
   - Пароль: `@GYMfV3Zvi!2nib`
   - Название: `Full Media` (необязательно)
4. Нажмите "Добавить аккаунт"

### 4.2 Синхронизировать кампании

1. На странице аккаунтов найдите добавленный аккаунт
2. Нажмите "🔄 Синхронизировать"
3. Подождите пока загрузятся кампании из SAPE

### 4.3 Создать отчет

1. Перейдите на http://localhost:5005/reports
2. Нажмите "+ Создать отчет"
3. Заполните форму:
   - **Кампания**: Выберите из списка
   - **Google Sheets URL**: Вставьте ссылку на вашу таблицу
   - **Название листа**: Оставьте пустым (или укажите конкретный лист)
   - **Ячейки**:
     - Показы: `B5`
     - Клики: `C5`
     - CTR: `D5`
     - Дата: `E5`
   - **Расписание**:
     - Дни: `1,5` (понедельник и пятница)
     - Время: `09:00`
4. Нажмите "Создать отчет"

### 4.4 Протестировать отчет

1. На странице отчетов найдите созданный отчет
2. Нажмите "▶️ Обновить сейчас"
3. Проверьте Google Sheets - данные должны обновиться

## 📊 Пример таблицы Google Sheets

Ваша таблица должна выглядеть примерно так:

| A          | B           | C          | D      | E                |
|------------|-------------|------------|--------|------------------|
| Метрика    | Значение    |            |        |                  |
| Кампания 1 |             |            |        |                  |
| Показы     | 1000        |            |        |                  |
| Клики      |             | 50         |        |                  |
| CTR        |             |            | 5.0%   |                  |
| Обновлено  |             |            |        | 21.04.2026 10:00 |

В настройках отчета вы указали:
- Показы: B5 (ячейка напротив "Показы")
- Клики: C5
- CTR: D5
- Дата: E5

## ❓ Решение проблем

### Ошибка "Invalid credentials" при синхронизации

- Проверьте правильность email и пароля SAPE
- Попробуйте войти вручную на https://traffic.sape.ru/

### Ошибка "Permission denied" в Google Sheets

- Убедитесь что Service Account email добавлен в настройки доступа таблицы
- Проверьте что права "Редактор" выданы
- Проверьте что `google_credentials.json` существует в корне проекта

### Метрики не обновляются

- Проверьте правильность адресов ячеек (B5, C5 и т.д.)
- Убедитесь что название листа указано правильно (или оставьте пустым для первого листа)
- Проверьте логи в разделе "Главная" > "Последняя активность"
