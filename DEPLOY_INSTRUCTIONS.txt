ЧТО ДЕЛАТЬ НА ПРОДАКШЕНЕ:
═══════════════════════════════════════════════════════════

1️⃣  Скопировать обновленные файлы:
   cd /root/api_google_sheets
   
2️⃣  Создать бэкап:
   mkdir -p backups/backup_$(date +%Y%m%d_%H%M%S)
   cp app.py backups/backup_$(date +%Y%m%d_%H%M%S)/
   cp main.py backups/backup_$(date +%Y%m%d_%H%M%S)/
   cp app/api/google_sheets_client.py backups/backup_$(date +%Y%m%d_%H%M%S)/

3️⃣  Обновить файлы с этой машины:
   # Эти файлы уже обновлены локально
   
4️⃣  Развернуть на сервере:
   ssh root@85.239.51.28
   cd /root/api_google_sheets
   
   # Скопируйте app.py и app/api/google_sheets_client.py
   # с локальной машины через scp
   
   cp app.py main.py
   systemctl restart sape-reports
   systemctl status sape-reports

5️⃣  Протестировать:
   - Попробуйте обновить отчет "Акира оил баннер"
   - Проверьте логи: journalctl -u sape-reports -n 100
   - Должна появиться детальная информация:
     * Какой worksheet ищется
     * Сколько строк в кэше  
     * Какие ID найдены в таблице
     * Первые ячейки для проверки формата
