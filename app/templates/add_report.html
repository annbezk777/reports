ℹ️ Справка: Частоты и разбросы

Как работает:

Частота = случайное число от (Частота - Разброс) до Частоты

Примеры с разбросом 0.5:

  • Частота 2.0 → диапазон от 1.5 до 2.0
  • Частота 3.0 → диапазон от 2.5 до 3.0
  • Частота 4.0 → диапазон от 3.5 до 4.0

Дневная и Тотальная частоты:

  • Дневная частота - используется для расчета охвата по каждому дню
  • Тотальная частота - используется для расчета общего охвата в строке "Всего"

⚠️ Важно:

  • Частота НИКОГДА не превышает указанное максимальное значение
  • Тотальная частота должна быть ≤ Дневной частоты
  • По умолчанию разброс = 0.1
  • Для отчетов с несколькими кампаниями используется среднее значение частот
