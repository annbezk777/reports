## 🔄 ПРАВИЛО РАЗРАБОТКИ:

**ДЛЯ ЛЮБОГО ИЗМЕНЕНИЯ:**
1. ✅ Сначала делаем ЛОКАЛЬНО
2. ✅ Тестируем на http://127.0.0.1:5006/reports
3. ✅ ТОЛЬКО после успешного теста обновляем ПРОДАКШЕН

### Процесс деплоя:

1. ✅ Подготовить код к деплою (коммит в Git)
2. ✅ Задеплоить на сервер (автоматически через GitHub Actions при `git push`)
3. ✅ Протестировать на сервере (http://74.208.242.125:5500)
4. ✅ **ОБЯЗАТЕЛЬНО** обновить локальную версию командой `./update_local.sh`
5. ✅ Проверить что локальная версия работает (http://127.0.0.1:5006/reports)
6. ❌ НЕ останавливать локальный сервер http://127.0.0.1:5006/reports до полного переноса

### Локальная версия:

- **URL:** http://127.0.0.1:5006/reports
- **Статус:** РАБОТАЕТ И НЕ ДОЛЖНА МЕНЯТЬСЯ
- **Запуск:** `cd ~/api_google_sheets && nohup venv/bin/python3 app.py > server_local.log 2>&1 &`
- **Остановка:** ТОЛЬКО после успешного деплоя и проверки сервера

### Безопасность:

- Всегда делать git commit перед деплоем
- Всегда иметь backup базы данных
- Тестировать на сервере перед изменением локальной версии

## 🔄 СИНХРОНИЗАЦИЯ ЛОКАЛЬНОЙ ВЕРСИИ

### ⚠️ ВАЖНО: Локальная версия = Backup

Локальная версия должна быть **ВСЕГДА актуальна** с продакшен-сервером.

### Как обновить локальную версию:

```bash
# После успешного деплоя на IONOS
cd ~/api_google_sheets
./update_local.sh
```

### Что делает скрипт обновления:

1. Получает последние изменения из GitHub (`git pull`)
2. Обновляет зависимости Python (если изменились)
3. Останавливает старый локальный сервер
4. Запускает обновленный сервер

### Проверка локального сервера:

```bash
./status_local.sh         # Проверить статус
tail -f server_local.log  # Посмотреть логи
```

### ⚡ АВТОМАТИЗАЦИЯ:

После каждого `git push origin main`:

1. **Автоматически:** Код деплоится на IONOS (GitHub Actions)
2. **Вручную:** Проверить работу на http://74.208.242.125:5500
3. **Вручную:** Обновить локальную версию: `./update_local.sh`
4. **Вручную:** Проверить локальную версию: http://127.0.0.1:5006/reports
