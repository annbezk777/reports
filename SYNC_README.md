# Синхронизация базы данных с сервером

## Быстрый старт

### Разовая синхронизация

Скачать базу данных с продакшн сервера один раз:

```bash
python3 sync_from_server.py
```

### Автоматическая синхронизация

Запустить автоматическую синхронизацию каждые 30 минут:

```bash
./auto_sync.sh 30
```

Или каждые 60 минут:

```bash
./auto_sync.sh 60
```

Для остановки нажмите `Ctrl+C`.

## Что делает скрипт

1. **Создает бэкап** текущей локальной базы в папку `backups/`
2. **Скачивает** актуальную базу с сервера `74.208.242.125`
3. **Заменяет** локальную базу на серверную
4. **Проверяет** что база скачалась правильно (показывает количество таблиц и записей)

## Бэкапы

Все бэкапы сохраняются в папке `backups/` с временной меткой:
- `backups/sape_reports_20261006_203000.db`
- `backups/sape_reports_20261006_210000.db`
- и т.д.

Можно безопасно удалять старые бэкапы вручную.

## Требования

- SSH доступ к серверу `root@74.208.242.125`
- Настроенный SSH ключ (чтобы не вводить пароль каждый раз)

### Настройка SSH ключа (если еще не настроено)

```bash
# Сгенерировать ключ (если нет)
ssh-keygen -t ed25519

# Скопировать ключ на сервер
ssh-copy-id root@74.208.242.125

# Проверить что работает без пароля
ssh root@74.208.242.125 "echo 'SSH работает!'"
```

## Решение проблем

### "Permission denied"

Убедитесь что у вас есть SSH доступ к серверу:

```bash
ssh root@74.208.242.125
```

### "Database locked"

Остановите локальный сервер перед синхронизацией:

```bash
# Найти PID процесса
lsof -ti:5006

# Остановить
kill <PID>

# Запустить синхронизацию
python3 sync_from_server.py

# Запустить сервер снова
nohup python app.py > server_local.log 2>&1 &
```

### Восстановить из бэкапа

Если что-то пошло не так:

```bash
# Посмотреть доступные бэкапы
ls -lh backups/

# Восстановить нужный бэкап
cp backups/sape_reports_20261006_203000.db sape_reports.db
```

## Интеграция с Git

Добавьте в `.gitignore`:

```
backups/
*.db
*.db-journal
```

База данных **не должна** коммититься в Git - только синхронизируется с сервера.
