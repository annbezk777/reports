## ❓ Частые вопросы

### Q: Можно ли использовать один credentials.json для обеих панелей?
**A:** Да, можно использовать один и тот же Service Account для всех проектов.

### Q: Что делать если порт 5007 занят?
**A:** Измените порт в systemd service файле и в Apps Script коде. Не забудьте открыть новый порт в файрволе.

### Q: Как перенести существующую базу данных на сервер?
**A:** Используйте scp:
```bash
scp "/Users/annabereznyak/Desktop/Все проекты/api_google sheets/database/sape_reports.db" root@69.48.201.233:/root/web-projects/sape-reports/database/
```

### Q: Можно ли запустить оба сервиса через один Nginx?
**A:** Да, можно настроить Nginx для проксирования обоих сервисов на разных путях или поддоменах.
