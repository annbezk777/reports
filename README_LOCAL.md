# 🖥️ Локальный сервер - Инструкции

## Управление локальным сервером

### ▶️ Запуск
```bash
./start_local.sh
```
Запустит сервер на http://localhost:5006

### 🛑 Остановка
```bash
./stop_local.sh
```

### 🔄 Перезапуск
```bash
./restart_local.sh
```

### 📊 Проверка статуса
```bash
./status_local.sh
```

## 🔧 Что делает start_local.sh

1. ✅ Проверяет наличие виртуального окружения (venv)
2. ✅ Создает его если отсутствует
3. ✅ Активирует виртуальное окружение
4. ✅ Устанавливает зависимости из requirements.txt
5. ✅ Проверяет что порт 5006 свободен
6. ✅ Запускает Flask сервер
7. ✅ Проверяет что сервер успешно запустился

## 📋 Полезные команды

### Просмотр логов
Логи выводятся в консоль при запуске сервера.

### Открыть в браузере
```bash
open http://localhost:5006
```

### Проверить какой процесс использует порт
```bash
lsof -Pi :5006 -sTCP:LISTEN
```

### Принудительно убить процесс на порту 5006
```bash
kill -9 $(lsof -ti:5006)
```

## 🆚 Локальный vs Продакшен

| Параметр | Локальный | Продакшен |
|----------|-----------|-----------|
| URL | http://localhost:5006 | http://85.239.51.28:5007 |
| База данных | `database/sape_reports.db` | `database/sape_reports.db` |
| Режим | Debug mode ON | Production mode |
| Сервер | Flask встроенный | Gunicorn |
| Автозапуск | Нет | Да (systemd) |

## ⚠️ Важно

1. **База данных одна и та же** - изменения на локальном влияют на продакшен и наоборот
2. **Credentials файлы** - используются те же Google Sheets credentials
3. **Порты разные** - локальный 5006, продакшен 5007

## 🔄 Синхронизация кода

Локальный сервер использует тот же код что и продакшен. Когда вы вносите изменения:

1. Тестируйте на локальном (localhost:5006)
2. Если все работает - перезапустите продакшен:
   ```bash
   ssh user@85.239.51.28
   sudo systemctl restart gunicorn
   ```

## 🐛 Проблемы и решения

### Ошибка: ModuleNotFoundError
**Решение:** Установите зависимости
```bash
source venv/bin/activate
pip install -r requirements.txt
```

### Ошибка: Address already in use (порт занят)
**Решение:** Остановите существующий процесс
```bash
./stop_local.sh
```

### Сервер не запускается
**Решение:** Проверьте логи
```bash
python3 app.py
```
Смотрите ошибки в выводе.

### Изменения в коде не применяются
**Решение:** Перезапустите сервер
```bash
./restart_local.sh
```

## 📞 Поддержка

Если возникли проблемы:
1. Проверьте статус: `./status_local.sh`
2. Посмотрите логи при запуске
3. Проверьте что порт 5006 свободен
4. Убедитесь что база данных существует в `database/sape_reports.db`
