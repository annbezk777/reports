# Adriver REST API - Результаты исследования

## 📋 Краткое резюме

После изучения официальной документации Adriver REST API обнаружено:

### ✅ Что доступно:
- **REST API**: https://api.adriver.ru
- **Документация**: https://www.adriver.ru/doc/restapi/
- **Аутентификация**: Работает через получение токена
- **Статистика**: Можно получить показы, клики через `/stat/ads/{id}`

### ❌ Критические проблемы:

1. **IVT данные НЕ доступны через REST API**
   - В официальной документации нет параметров для IVT/GIVT/SIVT
   - Эти метрики доступны только в:
     - Веб-интерфейсе
     - Excel выгрузках
     - Email отчетах

2. **api.adriver.ru недоступен**
   ```
   Connection timeout to api.adriver.ru:443
   ```
   Возможные причины:
   - Геоблокировка (доступ только из России)
   - Требуется whitelist IP-адреса
   - Корпоративный firewall
   - Требуется VPN

## 📚 Официальная документация

### Основные разделы:
- [Общая информация](https://www.adriver.ru/doc/restapi/general/)
- [Аутентификация](https://www.adriver.ru/doc/restapi/operation/)
- [Получение статистики](https://www.adriver.ru/doc/restapi/get-stat/)
- [Метрики и дашборды](https://www.adriver.ru/agency/legal/services/metrics-dashboards/)

### Аутентификация:

```bash
# 1. Получить токен
GET https://api.adriver.ru/login
X-Auth-Login: RTBsape
X-Auth-Passwd: Sape02082023

# Ответ:
<adriver:userId>12345</adriver:userId>
<adriver:token>%5DY%00%AA...</adriver:token>

# 2. Использовать для запросов
GET https://api.adriver.ru/stat/ads/300723?start_date=2026-10-01&stop_date=2026-10-31
X-Auth-UserID: 12345
X-Auth-Passwd: %5DY%00%AA...
```

### Доступные endpoints:
- `/stat/ads/{campaign_id}` - статистика обычных кампаний
- `/stat/net_ads/{campaign_id}` - статистика сетевых кампаний
- `/stat/profiles/{profile_id}` - статистика профилей/сценариев
- `/stat/slices/{slice_id}` - статистика слайсов
- `/stat/banners/{banner_id}` - статистика баннеров

**Параметры:**
- `start_date` - дата начала (YYYY-MM-DD)
- `stop_date` - дата окончания (YYYY-MM-DD)
- `granularity` - детализация (daily/hourly)

**Ответ содержит:**
- `<exp>` - показы
- `<click>` - клики
- `<subevent>` - кастомные события

**НЕ содержит:**
- ❌ IVT показы (%)
- ❌ GIVT показы (%)
- ❌ SIVT показы (%)
- ❌ GIVT клики (%)
